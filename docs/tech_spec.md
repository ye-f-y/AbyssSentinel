# 技术规范

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 硬件 | ESP32-S3 + RS485 Modbus | 气象传感器 + 土壤传感器并联 |
| 消息 | EMQX (本地) MQTT | 4个Topic频道 |
| 后端 | Python 3.12 + FastAPI | 规则引擎 + AI Agent + RAG |
| AI | 通义千问 Qwen-Plus | 阿里云API，Function Calling |
| 向量库 | ChromaDB (本地) | 国标规范检索 |
| 3D引擎 | Three.js v0.170 | 下凹立交桥城市数字孪生场景（`AbyssScene.vue`） |
| 前端 | Vue3 + Three.js + ECharts | 数字孪生大屏 + 图表 + MQTT.js |
| 构建 | Vite 6 | 前端开发服务器 |

> 注：项目早期使用 Cesium.js 3D地球，已于 2026-06-26 替换为 Three.js 下凹立交城市场景（`AbyssScene.vue`）。

## AI推演输出规范（5段结构）

AI推演终端输出严格遵循5段结构，每段以【段名】开头：

| 段落 | 说明 | 颜色标识 |
|------|------|---------|
| 【数据解读】 | 各传感器数值的含义及异常程度（2-4句） | 青色 |
| 【灾害链推演】 | 逐步推演灾害发展路径，序号标注（3-5句） | 金色 |
| 【国标依据】 | 引用规范条款，每条单独一行，含标准编号+条文号 | 绿色 |
| 【风险评级】 | NORMAL/WATCH/WARNING/CRITICAL + 理由 | 橙色 |
| 【决策说明】 | 是否排水及原因（1-3句） | 红色 |

### 后端保障机制
- **`_postprocess()`后处理**：正则提取5段，缺失段落用规则引擎数据补全，确保每段以句号结尾
- **`_fallback()`兜底**：AI不可用时仍保持5段结构化输出
- **`regulations_cited`正确传值**：检索到的规范来源列表传给前端

## 国标规范知识库

| 来源 | 说明 |

## 规则引擎判断标准

### 内涝风险指标
| 指标 | 阈值 | 依据 |
|------|------|------|
| 气压 | < 100 kPa | 气象学强降雨特征 |
| 气压 | < 99 kPa | 强对流天气气压特征 |
| 空气湿度 | > 85% | 气象观测经验 |
| 风速 | > 10.8 m/s | 6级以上风，强对流特征 |

### 边坡滑坡指标
| 指标 | 阈值 | 依据 |
|------|------|------|
| 土壤湿度 | > 75% | 边坡稳定性分析经验值 |
| 土壤湿度 | > 85% | 接近土壤饱和含水率 |
| 土壤EC值 | 突变 > 50% | 孔隙水压力变化特征 |

### 复合灾害指标
| 条件组合 | 说明 |
|----------|------|
| 气压<99.5 且 土壤湿度>80% | 暴雨+饱和土壤，立即排水 |

> 注：气压单位为 kPa（项目早期文档误写 hPa，已统一为 kPa）

## 一键演示5阶段流程

| 阶段 | 风险等级 | 传感器变化 | 3D场景 | AI推演 |
|------|---------|-----------|--------|--------|
| 1 正常监测 | NORMAL | 基线数据 | 晴天 | 系统自检 |
| 2 关注预警 | WATCH | 气压↓ 土壤↑ | 天空渐暗小雨 | 气压下降预示强对流 |
| 3 警告响应 | WARNING | 气压↓↓ 土壤↑↑ | 雨势加大积水 | 暴雨+土壤饱和，引用国标 |
| 4 紧急预警 | CRITICAL | 气压↓↓↓ 土壤↑↑↑ | 暴雨洪泛 | 复合灾害，立即排水 |
| 5 排水响应 | CRITICAL→NORMAL | 数据逐步恢复 | 泵站启动水位下降 | 排水反馈+系统总结 |

- 渐进式数据变化：`gradualChange()` 20步插值
- 顶部进度条显示阶段与百分比
- 可中断：再次点击重置为正常基线

## ESP32硬件配置（2026-06-27确认）

| 配置项 | 值 | 说明 |
|--------|-----|------|
| UART | UART1 | GPIO16=TX, GPIO17=RX |
| 波特率 | 9600 | 两个传感器一致 |
| 气象站地址 | 0x03 | 出厂默认0x02，已改为0x03 |
| 土壤传感器地址 | 0x02 | 出厂默认 |
| 继电器引脚 | GPIO15 | 控制排水泵 |
| WiFi | PC热点 192.168.137.x | ESP32 IP: 192.168.137.125 |
| MQTT Broker | 192.168.137.1:1883 | EMQX 运行在PC |

### 气象站寄存器 (RS-FSXCS-N01-3, addr=0x03)

| 寄存器 | 参数 | 换算 | 单位 |
|--------|------|------|------|
| 0x01F8 | 空气湿度 | ÷10 | %RH |
| 0x01F9 | 气温 | ÷10 | ℃ |
| 0x01FA | 噪音 | ÷10 | dB |
| 0x01FB | 风速 | ÷10 | m/s |
| 0x01FC | 风向 | 直接读 | ° |
| 0x01FD | 大气压 | ÷10 | kPa |
| 0x01FE | 风力等级 | 直接读 | 0-17级 |
| 0x01FF | 光照 | 直接读 | Lux |

### 土壤传感器寄存器 (SN-3001-TR-ECTHPH-N01, addr=0x02)

| 寄存器 | 参数 | 换算 | 单位 |
|--------|------|------|------|
| 0x0000 | 土壤湿度 | ÷10 | %RH |
| 0x0001 | 土壤温度 | ÷10 | ℃ |
| 0x0002 | EC | 直接读 | μS/cm |
| 0x0003 | pH | ÷10 | pH |

## 已知硬件问题

- **XY-485(HW-726) RS485自动方向模块**：MAX485芯片，TTL逻辑高电平阈值约3.5V（5V供电时），ESP32 GPIO 3.3V低于阈值 → 自动方向检测失败
- **当前方案C**：PC USB-RS485转换器桥接（`hardware/pc_bridge.py`），CH340芯片，Windows 11驱动有偶尔端口锁定bug
- **长期方案D**：MAX3485 3.3V兼容模块已订购，到货后替换XY-485，ESP32恢复直连传感器
