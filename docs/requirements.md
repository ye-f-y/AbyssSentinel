# 开发需求文档

## 项目定位
城市防汛与边坡灾害AI数字孪生预警系统。
核心逻辑：不等灾害发生，在暴雨前兆（气压骤降、土壤变湿）时由AI主动推演灾害链，提前执行预防措施。

## 功能清单

### 核心功能
1. 实时传感器数据展示 — 左侧悬浮卡片，气象+土壤数据跳动更新，带趋势箭头
2. 3D数字孪生场景 — Three.js 下凹立交桥城市，全屏铺底，数据驱动场景变化
3. AI推演终端 — 右侧悬浮卡片，打字机效果显示推理过程，引用国标条款
4. 风险仪表盘 — 四色风险等级指示，CRITICAL时闪烁
5. MQTT实时通信 — 后端接收传感器数据，AI分析后推送结果
6. 规则引擎 — 毫秒级快速判断风险等级
7. AI深度推演 — 通义千问 + 国标规范知识库RAG检索
8. 硬件控制 — ESP32继电器物理执行排水指令

### 额外功能
9. 一键演示模式 — 按钮触发5阶段全自动演示流程
10. 传感器数据模拟器 — 滑块调整数据，硬件离线也可用
11. 历史数据回放 — ECharts 趋势图实时绘制气压/土壤湿度曲线
12. 积水深度显示 — 底部悬浮卡片，实时显示积水深度与等级

### 后期迭代（本次不做）
- 手机端查看
- 语音播报预警
- 多城市切换（原计划，已删除，单场景聚焦下凹立交桥）

### 布局特点
- **悬浮卡片**：3D 场景全屏铺底，左右面板 `position: absolute` 悬浮其上
- **半透明**：传感器/风险/状态卡片半透明（0.35→0.22），可透出背后城市
- **AI 终端高不透明**：0.88，保证荧光绿代码文字可读
- **交互穿透**：面板容器 `pointer-events: none`，卡片本身 `auto`，点击卡片间隙可操作 3D 场景
- **趋势图拉宽**：`margin-right: -220px` 横向延伸 220px
- **模拟器智能切换**：开启模拟器时趋势图卡片替换为数据模拟器卡片（同位置）

## 按钮规范
- 数据模拟器按钮：默认蓝色渐变 + 白字，开启态 (`.active`) 实色蓝色 + 光晕
- 一键演示按钮：默认蓝色渐变 + 白字，运行中态 (`.demo.running`) 橙红渐变 + 脉冲动画
- 两按钮默认样式完全一致，仅状态切换时区分
