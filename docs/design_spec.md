# 设计规范

## 视觉风格：专业蓝色渐变 + Three.js 下凹立交桥城市

核心设计理念：专业数字孪生系统（Digital Twin），数据驱动的可视化。
Three.js v0.170 构建的下凹立交桥城市场景作为全屏背景层，UI 卡片悬浮其上，半透明毛玻璃质感。

> 注：项目早期使用 Cesium.js 3D地球，已于 2026-06-26 替换为 Three.js 下凹立交城市场景（`AbyssScene.vue`）。早期"梦幻紫粉地球"风格已于 2026-06-25 替换为专业蓝色渐变风格。旧组件与原型文件已于 2026-08-22 清理删除。

## 配色体系

### 基础色板

- 主色调：线性渐变蓝色 `#99c0fe → #4786d4`
- 主色变量：`--brand-start: #99c0fe` / `--brand-end: #4786d4`
- 主色渐变：`--brand-gradient: linear-gradient(135deg, #99c0fe 0%, #4786d4 100%)`
- 强调色（正常）：`#4786d4`（蓝）
- 强调色（关注）：`#f0c040`（淡金）
- 强调色（警告）：`#ff8800`（橙）
- 强调色（紧急）：`#ff3333`（红闪）
- 背景深色：`#0a1430`（深蓝黑）
- 面板背景：`rgba(15, 30, 70, 0.28)`（半透明深蓝）
- 文字主色：`#e8eef8`（亮白蓝）
- 文字次色：`#a8b8d0`（灰蓝）
- 终端文字：`#00ff88`（荧光绿，AI 推演代码）

### 悬浮卡片布局

- Three.js 场景：`position: absolute` 铺满主内容区，`z-index: 1`
- 左右面板：`position: absolute` 透明容器，`z-index: 2`
- 面板容器 `pointer-events: none`，卡片本身 `pointer-events: auto`
- 点击卡片间隙可操作 3D 场景（旋转/缩放/平移）

### 卡片透明度分级

| 卡片类型          | 不透明度        | 说明                       |
| ----------------- | --------------- | -------------------------- |
| 传感器数据卡片    | 0.35→0.22 渐变 | 半透明，可透出城市         |
| 风险等级面板      | 0.35→0.22 渐变 | 半透明，可透出城市         |
| 状态栏 / 规范标签 | 0.35→0.22 渐变 | 半透明，可透出城市         |
| AI 推演终端       | 0.88            | 高不透明度，保证代码可读性 |

### 卡片样式规范

- 背景：`linear-gradient(180deg, rgba(15,30,70,0.35) 0%, rgba(30,55,110,0.22) 100%)`
- 边框：`1px solid rgba(153,192,254,0.30)`
- 圆角：`12px`
- 阴影：`0 4px 16px rgba(0,0,0,0.25), inset 0 1px 0 rgba(255,255,255,0.10)`
- 毛玻璃：`backdrop-filter: blur(3px)`
- 悬停：边框加亮 + 背景加深 + 阴影增强
- 标题前标识条：`3px × 14px` 蓝色渐变小竖条

## 大屏UI元素

### 顶部标题栏

- 高度：68px
- 背景：深蓝渐变 `linear-gradient(90deg, rgba(15,30,70,0.92) 0%, rgba(30,55,110,0.88) 50%, rgba(15,30,70,0.92) 100%)`
- 主标题 "ABYSS SENTINEL"：Orbitron 字体，30px，白色，蓝色光晕
- 副标题：浅蓝 `#c8d6ec`，13px，黑色文字阴影
- 左侧：状态指示灯 + 实时时间
- 右侧：数据模拟器按钮 + 一键演示按钮

### 按钮规范

- 默认态：蓝色渐变背景 + 白字 + `#4786d4` 边框
- 悬停态：`var(--brand-gradient)` 实色渐变 + 上移 1px + 蓝色阴影
- 模拟器开启态 (`.active`)：实色蓝色渐变 + 光晕高亮
- 演示运行中态 (`.demo.running`)：橙红渐变 `#ff6b4a → #ff8a6a` + 脉冲动画

### 传感器面板（左侧）

- 面板宽度：600px（含 240px 右侧 padding 预留）
- 卡片：气象传感器 / 土壤传感器 / 气压与土壤湿度趋势（或数据模拟器）
- 趋势图卡片：`margin-right: -220px` 横向拉宽
- 模拟器开启时：趋势图替换为数据模拟器卡片（同位置）

### AI 推演面板（右侧）

- 面板宽度：360px
- 风险仪表盘：四色风险等级指示，CRITICAL 时闪烁
- 设备状态栏：设备/泵站/MQTT 三项状态指示
- 终端：深色背景 + 荧光绿文字，打字机效果

## 3D 场景规范（Three.js）

### 场景内容

- **场景**：下凹立交桥城市防汛数字孪生场景（`AbyssScene.vue`）
- **相机**：透视相机，初始位置 `(35, 28, 38)`，俯视角
- **控制**：OrbitControls，支持鼠标拖拽旋转/滚轮缩放/右键平移
- **光照**：环境光 + 主方向光（带阴影）+ 填充光 + 半球光
- **元素**：
  - 下凹立交桥地形（漏斗状）
  - 城市建筑群（程序生成）
  - 沥青道路（带车道线/裂缝纹理）
  - 警告标志牌（水深危险）
  - 水面（可上升下降）
  - 雨粒子系统
  - 泵站（排水时亮绿灯）

### 场景联动

| 触发条件          | 场景响应                           |
| ----------------- | ---------------------------------- |
| 风险等级 WATCH    | 天空渐暗，开始小雨                 |
| 风险等级 WARNING  | 雨势加大，路面开始积水             |
| 风险等级 CRITICAL | 暴雨倾盆，路面严重积水，洪泛面上升 |
| `relay_on=true` | 泵站亮绿灯，排水粒子启动，水位下降 |
| 风险等级降级      | 暴雨停止，积水自然消退             |

### 视觉风格

- 天空：暴风雨天空渐变球体
- 雾效：`FogExp2` 营造阴沉氛围
- 色调映射：`ACESFilmicToneMapping`（电影级）
- 阴影：`PCFSoftShadowMap` 软阴影
- 主色：与 UI 一致的蓝色调，与城市灰白建筑形成对比
